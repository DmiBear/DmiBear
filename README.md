# Дмитрий Поляков — Technical Writer

Технический писатель с более чем годом коммерческого опыта в IT.

Разрабатываю и сопровождаю документацию для информационных систем — от анализа исходных требований до эксплуатационных материалов, обучения пользователей и корпоративной базы знаний.

Работаю с крупными информационными системами, связанными комплектами документации и ассистированной подготовкой технической документации с использованием ИИ. Развиваю Docs-as-Code подход для публикации и сопровождения документации.

## Основные направления

- **Полный цикл документации информационных систем:** анализ ТЗ и требований → ЧТЗ → ПМИ → руководства пользователя и администратора → программы обучения → актуализация связанных документов после изменений и замечаний.
- **Проектная и эксплуатационная документация:** обеспечиваю согласованность требований, терминологии, ролей, пользовательских сценариев и критериев проверки между документами одного проекта.
- **Корпоративные базы знаний:** формирую единое документационное пространство по продуктам и проектам компании и выстраиваю единый подход к сопровождению материалов.
- **Обучение пользователей:** разрабатываю программы обучения, практические задания, критерии контроля и итоговую аттестацию.
- **ИИ-ассистированная документация:** формализую процессы работы технического писателя, структуру навыков, входные и выходные данные, правила проверки и точки контроля специалистом.
- **Интеграции и бизнес-процессы:** документирую взаимодействие веб-сервисов, сценарии передачи данных, авторизацию и внутренние бизнес-процессы.
- **Docs-as-Code:** Markdown, Git, MkDocs, GitHub Actions и автоматическая публикация документации.

## Ключевые кейсы

- **ГИСОГД** — разработка и актуализация комплекта проектной и эксплуатационной документации для государственной информационной системы обеспечения градостроительной деятельности.
- **Программа обучения ГИСОГД** — 10 вебинаров общей продолжительностью 22 академических часа, практические задания и итоговая аттестация.
- **Ассистированная подготовка документации с ИИ** — формализация процессов технического писателя и правил проверки документов.
- **Корпоративная база знаний** — развитие единого рабочего пространства для документации по продуктам и проектам.
