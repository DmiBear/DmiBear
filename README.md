# Дмитрий Поляков — Technical Writer

Технический писатель с более чем годом коммерческого опыта в IT.

Разрабатываю проектную, эксплуатационную и пользовательскую документацию для информационных систем. Работаю с требованиями, большими комплектами документов, пользовательскими сценариями, бизнес-процессами и интеграциями.

## Профессиональные направления

- **Проектная и эксплуатационная документация:** ЧТЗ, ПМИ и сопутствующие проектные документы.
- **Пользовательская и административная документация:** руководства пользователя и администратора; разделяю материалы по ролям и сценариям работы, формируя отдельные контуры документации для разных аудиторий.
- **Документация интеграций и бизнес-процессов:** передача данных между системами, формы, API-сценарии, внутренние процессы.
- **Корпоративные базы знаний:** структурирование и сопровождение документации по продуктам и рабочим процессам.
- **Docs-as-Code:** подготовка и публикация документации с использованием Markdown, Git, MkDocs и GitHub Actions.
